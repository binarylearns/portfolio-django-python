# Ishwor Adhikari — Developer Portfolio

A modern, responsive personal portfolio website built with **Tailwind CSS** and vanilla **JavaScript**. Features a bold yellow-and-black color scheme, smooth animations, and a fully functional dark/light mode toggle.

## ✨ Features

- 🎨 **Yellow & Black Theme** — Bold, high-contrast design with a signature yellow accent
- 🌓 **Dark / Light Mode Toggle** — Persists user preference via `localStorage`
- 📱 **Fully Responsive** — Looks great on mobile, tablet, and desktop
- 🎬 **Scroll Reveal Animations** — Sections fade in smoothly as you scroll
- 📊 **Animated Skill Bars** — Progress bars animate when the skills section enters view
- 🧭 **Active Nav Highlighting** — Nav links highlight based on current scroll position
- 📱 **Mobile Menu** — Collapsible hamburger navigation for small screens
- 🚀 **Smooth Scrolling** — Anchor links scroll with proper header offset
- ♿ **Accessible** — ARIA labels, semantic HTML, and keyboard-friendly interactions
